# Class Names & Custom CSS

Every component renders with two stable class hooks:

- `retro-ui` — present on every component in the library
- `<component>-root` — specific to each component (`button-root`, `card-root`, `modal-root`, etc.)

You can target these from any stylesheet to restyle the whole library at once, or just one component.

## Restyle everything

<Source
	dark
	language="css"
	code={`.retro-ui {
	font-family: 'Perfect DOS VGA 437', 'Courier New', monospace !important;
}`}
/>

## Target a specific component

<Source
	dark
	language="css"
	code={`.button-root {
	letter-spacing: 0.5px;
}

.card-root {
	max-width: 480px;
}`}
/>

## Per-instance overrides with `sx`

For one-off changes, the `sx` prop is usually cleaner — it accepts standard CSS in object form and has access to the theme:

<Source
	dark
	language="tsx"
	code={`import { Button } from 'retro-react';

<Button
	variant="outline"
	sx={{
		minWidth: 160,
		'&:hover': { backgroundColor: '#ffe1e1' },
	}}
>
	Custom hover
</Button>`}
/>

Each component's docs page lists any **additional** class names it exposes for child elements (e.g. `card-header`, `modal-close-button`).
