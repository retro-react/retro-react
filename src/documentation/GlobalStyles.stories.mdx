# Global styles and theming 🎨

Retro React is built on [Theme UI](https://theme-ui.com) + [Emotion](https://emotion.sh). The default Win95-flavoured theme is baked in, and you can override anything you like.

## Wrap your app

Most consumers don't need to do anything here. Components ship with the default theme. To override colors or extend the theme, wrap your app:

<Source
	dark
	language="tsx"
	code={`import { ThemeProvider, defaultTheme } from 'retro-react';

const myTheme = {
	...defaultTheme,
	colors: {
		...defaultTheme.colors,
		primary: '#003366',
		secondary: '#cc0066',
	},
};

export default function App({ children }) {
	return <ThemeProvider theme={myTheme}>{children}</ThemeProvider>;
}`}
/>

## What the theme contains

The `defaultTheme` export gives you a typed view of every token:

<Source

	language="ts"
	code={`{

		success: '#00FF41',     // CRT green
		error: '#AA0000',
		warn: '#FFFF55',
		text: '#000000',
		greyscale: '#C0C0C0',
		'greyscale-dark': '#808080',
	},
	gui: {
		buttonFace: '#C0C0C0',
		buttonShadow: '#808080',
		buttonHighlight: '#FFFFFF',
	},
	terminal: {
		background: '#000000',
		foreground: '#00FF41',
	},
	// ...shades, etc.
}`}
/>

## Styling individual components

Every component accepts an `sx` prop for one-off styling, with access to the theme:

<Source
	dark
	language="tsx"
	code={`import { Button } from 'retro-react';

<Button
	sx={{
		minWidth: 200,
		px: 3,
		'&:hover': { filter: 'brightness(1.1)' },
	}}
>
	Wide Button
</Button>`}
/>

## Re-using the emotion primitives

If you need to write your own styled components, the Emotion helpers are re-exported so you only need one import:

<Source
	dark
	language="tsx"
	code={`import { styled, useTheme, css } from 'retro-react';

const MyStyledButton = styled.button\`
	background: \${(p) => p.theme.colors.primary};
	color: #fff;
	border: 2px solid;
	border-color: #fff #808080 #808080 #fff;
	padding: 4px 12px;
	font-family: 'MS Sans Serif', sans-serif;
\`;

function Hello() {
	const theme = useTheme();
	return <MyStyledButton>Hello, {theme.colors.primary}</MyStyledButton>;
}`}
/>
