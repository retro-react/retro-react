# Retro React 📟

> A React component library inspired by Windows 95/98 — authentic bevels, sharp pixels, and 50+ accessible, typed components.

## Install

```bash
npm install retro-react
```

That's it. `@emotion/react`, `@emotion/styled`, and `theme-ui` install automatically. React is the only peer dependency (16.8 – 19).

## Quick start

<Source
	dark
	language="tsx"
	code={`import { Button, Card, Input } from 'retro-react';

export default function App() {
	return (
		<Card header="Sign in">
			<Input placeholder="Username" />
			<Button variant="primary">OK</Button>
			<Button variant="outline">Cancel</Button>
		</Card>
	);
}`}
/>

## What's in the box

- **50+ components** — Button, Input, Select, Modal, Drawer, Tabs, Accordion, Table, Tree, Tooltip, ProgressBar, Pager, CRT, Terminal, WordArt, and more.
- **Controlled & uncontrolled** — Every stateful component supports both patterns (`value` / `defaultValue`, `open` / `defaultOpen`, etc.).
- **TypeScript-first** — Full type definitions ship with the package; props are documented inline.
- **Accessible** — Proper ARIA roles, keyboard navigation, focus traps where it matters.
- **Tree-shakeable** — Single ESM + CJS bundles with `sideEffects: false`.
- **Tiny core** — ~300 KB minified, no peer dep installs required.

## Controlled vs uncontrolled

Most stateful components work both ways out of the box:

<Source
	dark
	language="tsx"
	code={`// Uncontrolled — the component manages its own state
<Accordion title="Settings" defaultOpen>
	General preferences…
</Accordion>

// Controlled — your state, your rules
const [open, setOpen] = useState(false);
<Accordion title="Settings" open={open} onToggle={setOpen}>
	General preferences…
</Accordion>`}
/>

Same pattern for `Tabs`, `Switch`, `Slider`, `Select`, `RadioGroup`, `Carousel`, `Tree`, `ToggleButtonGroup`, `Popover`, and more.

## Theming with `sx`

Every component accepts the `sx` prop ([Theme UI](https://theme-ui.com)) for one-off styling, with full theme access:

<Source
	dark
	language="tsx"
	code={`<Button
	sx={{
		minWidth: 200,
		'&:hover': { filter: 'brightness(1.1)' },
	}}
>
	Wide Button
</Button>`}
/>

## Global styling

Every rendered element carries a `retro-ui` class plus a component-specific `<name>-root` class — so you can blanket-style across the library:

<Source
	dark
	language="css"
	code={`.retro-ui {
	font-family: 'Perfect DOS VGA 437', monospace !important;
}

.button-root {
	letter-spacing: 0.5px;
}`}
/>

See the [CSS docs](/docs/css-general--docs) for the full class-name map.
