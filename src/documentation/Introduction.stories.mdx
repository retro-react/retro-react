# Retro React 📟

A React component library that looks like Windows 95/98. 50+ typed, accessible components with classic 3D bevels and sharp pixel edges.

## Install

```bash
npm install retro-react
```

That's it. `@emotion/react`, `@emotion/styled`, and `theme-ui` install automatically. React is the only peer dependency (16.8 through 19).

## Quick start

<Source
	dark
	language="tsx"
	code={`import { Button, Card, Input } from 'retro-react';

export default function App() {
	return (
		<Card header="Sign in">
			<Input placeholder="Username" />
			<Button variant="primary">OK</Button>
			<Button variant="outline">Cancel</Button>
		</Card>
	);
}`}
/>

## What's in the box

50+ components, including Button, Input, Select, Modal, Drawer, Tabs, Accordion, Table, Tree, Tooltip, ProgressBar, Pager, CRT, Terminal, WordArt, and more (see the full list below).

Every stateful component supports both controlled and uncontrolled use (`value` / `defaultValue`, `open` / `defaultOpen`). Full TypeScript types ship with the package and the props are documented inline.

ARIA roles, keyboard navigation, and focus traps are in place where they matter (Modal, Drawer, Tree, Menu, Tabs, Combobox).

The whole thing is a single ESM + CJS bundle, ~300 KB minified (118 KB gzipped), `sideEffects: false` so your bundler can tree-shake.

## Controlled vs uncontrolled

Most stateful components work either way:

<Source
	dark
	language="tsx"
	code={`// Uncontrolled. The component manages its own state.
<Accordion title="Settings" defaultOpen>
	General preferences...
</Accordion>

// Controlled. You manage state.
const [open, setOpen] = useState(false);
<Accordion title="Settings" open={open} onToggle={setOpen}>
	General preferences...
</Accordion>`}
/>

Same pattern works for `Tabs`, `Switch`, `Slider`, `Select`, `RadioGroup`, `Carousel`, `Tree`, `ToggleButtonGroup`, `Popover`, and others.

## Theming with `sx`

Every component accepts an `sx` prop ([Theme UI](https://theme-ui.com)) for one-off styling, with full theme access:

<Source
	dark
	language="tsx"
	code={`<Button
	sx={{
		minWidth: 200,
		'&:hover': { filter: 'brightness(1.1)' },
	}}
>
	Wide Button
</Button>`}
/>

## Global styling

Every rendered element carries a `retro-ui` class plus a component-specific `<name>-root` class, so you can blanket-style across the library:

<Source
	dark
	language="css"
	code={`.retro-ui {
	font-family: 'Perfect DOS VGA 437', monospace !important;
}

.button-root {
	letter-spacing: 0.5px;
}`}
/>

See the [CSS docs](/docs/css-general--docs) for the full class-name map.
